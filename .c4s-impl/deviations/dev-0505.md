## What I found

M01 row `--mode` and AC ac-mode-dev-prod-seeduje-pole-mode-wy: the flag seeds `mode` of a new entry only and "dla istniejącego jest ignorowana". Read literally: the process runs in the selected entry's mode, the flag changes nothing for an existing entry (before 2.1.58 the process ran in the flag's mode for that run). Consequence for development: `npm run dev` (`--mode dev`) on a machine whose `default` entry is `prod` serves the built statics instead of Vite. Implemented literally; if the dev script should keep forcing dev for the run, the row should say the flag is a process override that is not persisted.

## Suggestion

State it in the specification (r7ozfsa9). Implemented meanwhile as: ASSUMPTION:dev-0505 — `--mode` for an existing entry is ignored entirely: the process runs in the entry's own mode.
