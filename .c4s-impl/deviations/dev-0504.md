## What I found

The flag-combination table (M31 qglsgonq) has `--workspace X --cwd Y` with "brak wpisu X → nowy wpis X z katalogiem domowym Y" and, in the next row, a refusal when "Y jest home innego wpisu" — the two overlap when X is new and Y is already another entry's home. Assumed: the refusal wins (WORKSPACE_HOME_MISMATCH, hint `--workspace <owner>`), so one directory never becomes the home of two entries.

## Suggestion

State it in the specification (qglsgonq). Implemented meanwhile as: ASSUMPTION:dev-0504 — a new name over a directory that already is a home is refused too.
