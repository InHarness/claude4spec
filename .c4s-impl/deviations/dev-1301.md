## What I found

`<current_skill>` is emitted "when the user has a file of a `skills`-kind root open", and its template carries `slug` (the package) and `file` (the path inside the package). A loose file at the top level of the root (edge case 9 in `rkbsi6ky`: no accordion, outside every package, not in the registry) has no package slug, so neither template variant can be filled. Built: a loose file gives no `<current_skill>` (and, being of a non-`pages` root, no `<current_page>` either). The specification should say whether a loose file gets a block, and with what attributes.
