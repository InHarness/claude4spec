## What I found

`mcp-tool-list` (at 2.1.19, unchanged in this window) says the default grouping is "by the `srv-*` tag". The dependencies section of `c4s-plugin-mcp-tools` (`dktzfo4k`) says grouping goes through two mirror tags, `mNN` and `srv-{server}`. The code (since 0.2.33, `grouping.ts` `groupByServer`) groups by the `server` **field**. It deliberately dropped the `srv-{server}` mirror tag, and the detail does no tag policing either. A user sees the same result either way: one group per server, with the server name as the heading. So the window's change (groups laid out by the catalog's `GroupedEntityList`) was built on the field grouping and not switched back to tags (marker `ASSUMPTION:dev-1904`).

## Suggestion

In `mcp-tool-list` and in `dktzfo4k`, say "grouped by the `server` field" and drop the `srv-*` mirror-tag wording. If tag grouping is still intended, say so explicitly and it will be built in the next window.
