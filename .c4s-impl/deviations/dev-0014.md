## What I found

At 2.1.8 two places describe plan anchor injection differently. M06 L7 (o8crf4hk, R7) says the `plans` kind gets anchors 'by the same definition as a page' (`m06-anchor-injection`), and the page path anchors headings of all six levels (M06 indexer step: 'Nagłówki wszystkich sześciu poziomów'). M10 'Przebieg wywołania' step 2, also at 2.1.8, says a plan gets an anchor before every `##`/`###`/`####` without one. The code follows M10, as it did before this window: `injectArtifactAnchors` (src/server/services/anchor-injection.ts) anchors H2-H4 only, while the page path anchors every heading. The build keeps H2-H4 for plans, because M10 names the levels outright and changing them would add anchors to every existing plan's `#` title and `#####` detail on the next write.

## Suggestion

either say in M06 that the plans kind anchors only `##`-`####` (one definition, a per-kind level range), or drop the level list from M10 so plans anchor every heading like pages.
