## What I found

Step 5 of the start's selection rule (m31wsel01) skips entries whose home directory is gone, but it does not say what a bare start does when every entry is skipped and one of them is named `default` (e.g. the only entry was created by `--workspace default --cwd X`, then X was deleted). Creating a second `default` would duplicate the workspace identity (the name).

## Suggestion

State it in the specification (m31wsel01, step 5). Implemented meanwhile as: ASSUMPTION:dev-0507 — the skipped `default` is neither reused nor replaced; the bare start creates a registry workspace on the first free port from 4500 whose `ws-<port>` name is also free, named `ws-<port>` (the step-3 fallback name), which later bare starts select as the sole candidate.
