## What I found

M13 `lbqrd6xh` says "Reset to default order — usuwa klucz", and the reset is saved with the `#entities` card's shared [Save] (PATCH /config). The DTO `patch-config-request` types `elementsMenu` as the entry array only (no `null`), and the PATCH contract has no other way to delete a key from `config.json`. So the spec does not say how [Save] removes the key.

Implemented (non-blocking assumption, marked `ASSUMPTION:dev-0001` in code): PATCH accepts `elementsMenu: null`, which removes the key from the file (no type check, no save rule); the response then omits the field. Built as a generic field-registry flag `nullRemovesKey` (set only on `elementsMenu`) and `writeConfig(cwd, partial, remove)`.

## Suggestion

In `patch-config-request`, type the `elementsMenu` field as `(…)[] | null` with the description "null removes the key (Reset to default order)". In M13 `lbqrd6xh`, state that the reset is saved as `elementsMenu: null`.
