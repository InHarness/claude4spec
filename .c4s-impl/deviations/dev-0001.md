## What I found

DTO entity-version-meta declares `changeSummary` as `string`, required. The code has always typed it `string | null`: `entity_version.change_summary` is a nullable column, and legacy and no-summary captures (`captureEntitySnapshot(..., summary: null)`) carry `null`. The window 2.1.24→2.1.25 changed only `releaseId`, and the goal says nothing is removed. So the row keeps `changeSummary: string | null`, and no empty summary is invented.

## Suggestion

declare the field `string | null` in the DTO, or say that the host coalesces a missing summary.
