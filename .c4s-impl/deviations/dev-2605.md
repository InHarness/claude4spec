## What I found

At 2.1.26 the mcp-tool `page-tools-move-page` `logic` says a root without a record store answers `NOT_IMPLEMENTED`, and the code does (services/page-write.ts `movePage`). The spec-operation `move-page` `kodyBledow` (PAGE_CONFLICT, PAGE_EXISTS, NOT_FOUND, ROOT_NOT_FOUND, INVALID_ARGUMENT, VALIDATION) does not list it, while `error-code-once` asks every code to be declared once on the record. Built: the catalog row declares exactly `kodyBledow` (NOT_IMPLEMENTED dropped from the row); the behaviour is unchanged (in a mounted project every page root has a record store, so the code is unreachable outside test rigs). Needed from the spec: add NOT_IMPLEMENTED to `move-page.kodyBledow`, or drop it from the tool's `logic` (and the code can then raise INTERNAL like the other page writes do for a store-less root).
