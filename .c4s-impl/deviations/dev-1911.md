## What I found

The design-system manifest sketch (section `dsmanifest` of `plugins/modules/c4s-plugin-frontend-mockups/design-system.md`, at 2.1.19) gives `displayOrder: 6` and `sidebarTab.order: 6`. The code has used 60 for both since before this window: `DESIGN_SYSTEM_DISPLAY_ORDER` in `src/identity.ts`, a value inherited from the host registration (ui-view 40, ac 50, design-system 60). The 2.1.18→2.1.19 change to that section only removes `sidebarTab.emptyState`.

What was done: the value was not changed (`ASSUMPTION:dev-1911`), because 6 would reorder the sidebar against the host-scale positions of the other tabs.

## Suggestion

Either write 60 in the sketch, or say which scale sidebar orders use.
