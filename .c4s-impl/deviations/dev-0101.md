## What I found

M02 `gj2vdsjm` (after 2.1.9) says an unknown root is reported by the AGENT channel as `NOT_FOUND` (an unknown `(rootId, relPath)` pair) and by REST as `404 ROOT_NOT_FOUND`. The L3 catalog rows of the four page write operations (`create_page`, `update_page`, `delete_page`, `move_page`) list `ROOT_NOT_FOUND`, and the code answers `ROOT_NOT_FOUND` in every channel (MCP `page-tools` included, with the roots that have a facade in `hint`). The two places disagree. Assumed: keep `ROOT_NOT_FOUND` on every channel (catalog wins, channel parity); only the domain of `rootId` changed (roots with a facade). The spec should either change `gj2vdsjm` to `ROOT_NOT_FOUND` or the catalog rows to `NOT_FOUND` for the agent channel.
