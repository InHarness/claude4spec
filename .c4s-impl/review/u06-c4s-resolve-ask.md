# Review notes — u06-c4s-resolve-ask (non-blocking)

- **rev-0001** `src/server/services/ask-answer.ts:53` — 'Plans the turn left' is a project-wide before/after diff of listPlans(). Any plan created or changed by another thread (chat UI, another ask) during this ask turn, which can run for minutes up to ASK_TURN_TIMEOUT_MS, is attributed to this turn and its path is appended to the answer sent to the caller. Narrow the set to plans linked to this thread (PlanService already tracks plan→thread links, e.g. findLastThreadIdForPlan / threads on create).
- **rev-0002** `src/server/services/ask-answer.ts:80` — The scrub only covers deps.cwd (and its realpath). A peer root whose `dir` lies outside the project directory (deps.roots) still leaks absolute paths into the answer, e.g. a page path the agent quotes from such a root. Consider scrubbing every root dir (rewritten relative to the project) too, so 'no absolute path into the peer project' holds for all of its roots.
- **rev-0003** `src/server/services/ask-answer.ts:98` — The `<dir>/rest` → `rest` replacement has no left boundary, so the directory is also stripped when it occurs inside a longer token: `file:///Users/x/proj/a.md` becomes `file://a.md`, `/mnt/backup/Users/x/proj/a` becomes `/mnt/backupa`. Add a left guard (start, whitespace, quote, backtick, paren, or `file://`) so only a path that starts with the directory is rewritten.
- **rev-0004** `.claude/skills/c4s-spec-reader/SKILL.md:42` — The tracked, hand-edited copy of the spec-reader skill still documents `--format json` as `{ content, resolved: [...] }`. The wire shape is now `{ format, text, resolved }` with `kind/start/end` entries, and the generated template was updated. The implementer skipped this copy on purpose (it is hand-edited), but agents in this repo read this copy, so a human should decide whether to update it in the same change.
